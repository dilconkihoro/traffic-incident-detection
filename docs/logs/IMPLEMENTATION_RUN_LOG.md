## 2026-09-28 Config bug: standin mode did not override a stray TW_WEIGHTS (session 2)
- Command(s): investigated a real failure reported from the web dashboard: `weights contract violated: weights file not found: weights/changeme-set-run-id/best.pt` on a run started with the standin flag on. Read `src/trafficwatch/config.py` end to end rather than guessing.
- Output (trimmed): root cause confirmed in code: `load_config(path, standin=True)` patches the YAML data's `detector.weights` to the real stand-in path via `_with_standin`, but `parse_config` separately applies `env.get("TW_WEIGHTS")` as a higher-priority override (`weights_override or weights` in `_detector`), regardless of whether standin mode was requested. `.env.example` ships `TW_WEIGHTS=weights/changeme-set-run-id/best.pt` as a documented placeholder; once a user copies it to `.env` and the webapp backend loads it (`uvicorn --env-file .env`), that placeholder becomes a real, truthy environment value that silently wins over the standin substitution.
