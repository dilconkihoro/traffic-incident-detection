# Training run log

One section per run, appended before the next run starts. Numbers come from `results.csv`, `model_card.json`, and the Colab output pasted back by the author. Runbook: `../04_COLAB_TRAINING.md`.

## Template

```
## <RUN_ID>
- Date:
- Purpose:
- Dataset tar and SHA-256:
- Split counts (train / val / dhaka_val), stride, class map version:
- Model and base weights:
- Hyperparameters (epochs, batch, imgsz, seed, patience, any non-default with reason):
- Hardware (nvidia-smi GPU string), wall time, sessions and resumes:
- Versions (ultralytics, torch, python):
- Best epoch and val metrics (precision, recall, mAP50, mAP50:95):
- Cross-domain metrics (dhaka_val), if applicable:
- Artifact path (Drive) and local weights path:
- Verdict and next action:
```
